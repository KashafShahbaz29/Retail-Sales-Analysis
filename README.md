# Retail Sales Analysis Using Python

## Project Overview
An exploratory data analysis (EDA) project using Python to analyze retail sales, profitability, customer segments, and product performance.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
**Sample Superstore Dataset**
- 9,994 original records
- 13 columns
- 9,977 records after removing duplicates

## Analysis Performed
- Data exploration and cleaning
- Statistical analysis
- Sales and profit by category
- Regional sales and profit analysis
- Sub-category performance
- Customer segment analysis
- Shipping mode analysis
- Discount vs. profit analysis
- Correlation analysis
- Data visualization

## Key Findings
- Technology generated the highest sales and profit.
- West was the top-performing region.
- Consumer segment generated the highest sales and profit.
- Copiers had the highest sub-category profit.
- Tables recorded the biggest loss.
- Higher discounts were generally associated with lower profits.
